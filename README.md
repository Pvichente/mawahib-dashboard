# Mawahib Project: MSME Empowerment Dashboard 📊

## Overview
**Mawahib** is a strategic collaboration between **Fundes** and **Coca-Cola** designed to empower Micro, Small, and Medium Enterprises (MSMEs), specifically grocery store owners. Through the **Enably** platform, users access specialized training modules in:
* Inventory Planning
* Business Management
* Financial Literacy

This dashboard provides stakeholders with real-time visibility into user engagement, lesson completion rates, and key performance indicators (KPIs) to support data-driven decision-making.

## Key Features
- **Strategic KPIs:** Monitor total registered users, active participation, and graduation rates[cite: 3, 4, 6].
- **Learning Funnel:** Visualize the conversion from pre-loaded users to certified graduates[cite: 41].
- **Geographic Analysis:** Heatmap of user locations to identify regional impact[cite: 40].
- **Business Segmentation:** Insights into user demographics, education levels, and business types[cite: 33, 45, 46].

## Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Data Manipulation:** Pandas
- **Visualization:** Plotly & Mapbox

## Data Sources
The dashboard processes data from:
